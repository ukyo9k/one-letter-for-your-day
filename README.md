## The letter

**D — for "doomscrolled".**

The day behind this letter: a whole day lost to the feed. Woke up meaning to check one message, looked up hours later with a dead phone battery, a stiff neck, and a head full of other people's disasters. "Doomscrolled" is the honest report of that day — vivid (thumb, screen glow, 2 a.m.), funny in the self-inflicted way, and true: everyone has had that day.

## What the program does

`main.py` (Python 3, standard library only) writes exactly one character — the letter **D** — to `/output/entry.txt`. Nothing else: no word, no gloss, no punctuation. The letter is held as a constant, validated to be exactly one character A–Z by `validate()`, and then written out.

## Run it

```sh
python3 main.py
cat /output/entry.txt   # D
```
